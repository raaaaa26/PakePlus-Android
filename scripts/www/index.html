使用说明

1. 配置接口　点右上角 ⚙，填接口地址和 API Key。填完后点 「探测模型」，会自动请求 /v1/models 列出可用模型，筛选项里点一下即可填入。探测不到也可以手动输入模型名。

⚠️ 设置会丢？　如果你在打包应用（如 HTML Pocket）或隐私模式下打开，浏览器可能禁止本地存储，刷新后设置就没了。
解决办法：设置面板里点 「生成配置链接」，把设置写进网址并收藏那个网址——以后用收藏的链接打开，设置就一直在。也可以用「导出配置」存成文件备着。

2. 拍题　点「拍照」调用系统相机，或点「相册」选已有图片。最多两张——一道题跨两页时分别拍上下两页，会自动合并理解成一道完整题目。

3. 逐步精讲　点「开始精讲」后进入对话模式：识别到的题目原文钉在页面顶部始终可见；讲解一块一块出现，点「下一步」看下一块。解答较长时会自动拆成若干小步，一步步带你推进。

4. 动手做测验　讲解中会穿插小测验，有三种：多选一（点选项，程序立刻判对错）、填空（在横线里填）、说一说（写思路，AI 会点评）。答错不要紧，会给出解析，还能点「重做」。

5. 随时提问　输入框常驻页面底部，任何时候都能打字提问，AI 会带着题目和已讲内容回答。

快捷键　Enter 发送（Shift+Enter 换行）· Esc 返回上传页重新拍题 · 下滑时顶栏会自动收起
